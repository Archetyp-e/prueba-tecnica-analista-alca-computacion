# Prueba Técnica: Analista de Datos y Automatización - TechStore

Este repositorio contiene la solución oficial desarrollada para la evaluación técnica del cargo de Analista de Datos y Optimización para Alca Computación. El proyecto abarca desde la conexión e ingeniería de datos en un entorno relacional local hasta la propuesta estratégica de negocio.

## 🛠️ Estructura del Proyecto

* **`Solución_prueba_Gabriel_Cornejo_Valdebenito.ipynb`**: Cuaderno principal de Google Colab que contiene los pipelines de extracción en SQL, limpieza de Data Quality (RUTs duplicados/nulos) y modelamiento con Pandas (Python).
* **Lógica de Negocio (Excel/Sheets)**: Diseño e implementación de un flujo optimizado con fórmulas avanzadas (`XLOOKUP` anidados), segmentación de tickets y reportes dinámicos de facturación por áreas de negocio.
* **Estrategia Comercial**: Análisis de fluctuación de ingresos y propuestas accionables de retención y estandarización para el funnel de ventas.

## 🚀 Tecnologías Utilizadas

* **Python 3.12**
* **Pandas & SQLite3**
* **Google Sheets**
